# Offline Installation

1. Build the ZIP with `./gradlew buildPlugin`.
2. Open IntelliJ.
3. Open Settings / Preferences.
4. Select Plugins.
5. Click the gear icon.
6. Select Install Plugin from Disk.
7. Select `build/distributions/digital-ai-workbench-intellij-0.1.0.zip`.
8. Restart IntelliJ.
9. Open View -> Tool Windows -> Digital AI Workbench.
10. Open Settings if you need to change the marketplace URL or branch.
11. Click Refresh Catalog.
12. Select a plugin.
13. Click Install for Me.
14. Restart IntelliJ or reopen GitHub Copilot Chat to reload personal customizations.

GitHub Copilot for JetBrains is required to use installed custom agents and skills.

Installed agents go to `~/.copilot/agents/`.
Installed skills go to `~/.copilot/skills/`.
